# 三态对决 🎮❄️💧💨

一款为**七年级物理「物质三态变化」**课堂设计的对抗性卡牌游戏（网页版）。把六种物态变化变成出牌规则，把吸热放热变成资源系统——学生为了赢，必须主动搞懂每种变化的**起点状态、终点状态、吸放热**三要素。

> 单文件网页游戏，无需安装、无需联网，双击即玩，投屏即可开课。

---

## 🚀 快速开始

1. 双击 `三态对决.html`（或部署到任意静态服务器 / 资料库云端页面）
2. 右上角选择模式：**双人对战（同屏）** 或 **人机对战**
3. 先到 **10 分** 的玩家获胜

## 🎯 教学目标

| 游戏 | 知识 |
|---|---|
| 出变化牌 | 六种物态变化的方向（固⇄液⇄气、固⇄气直变） |
| 支付能量牌 | 吸热（熔化/汽化/升华）与放热（凝固/液化/凝华） |
| 合法性提示 | 常见误区：凝华不经过液态、"白气"≠水蒸气等 |
| 三连击 | 水循环变化链的综合理解 |

## 🃏 牌组构成（40 张）

| 牌型 | 数量 | 作用 |
|---|---|---|
| 🔥 加热（吸热▲） | 10 | 能量牌，出变化牌的"燃料" |
| ❄️ 冷却（放热▼） | 10 | 能量牌，出变化牌的"燃料" |
| 🔄 变化牌（熔化/凝固/汽化/液化/升华/凝华） | 16 | 完成相变得分的核心牌 |
| ⚔️ 干扰牌（保温杯/风口/热浪/寒流） | 4 | 打乱对手节奏 |

## 📜 游戏规则

### 出牌（核心规则）

打出一张**变化牌**必须同时满足两个条件：

1. **起点状态正确**：你场上的物质必须处于该变化的起始状态
   - 例：「熔化」需要你当前是**固态**
2. **支付配对能量牌**：自动消耗对应能量
   - 吸热变化（熔化/汽化/升华）→ 消耗「加热」
   - 放热变化（凝固/液化/凝华）→ 消耗「冷却」

成功后：物质状态改变、**+2 分**，回合结束自动补 2 张牌。

### 合法性判定（教学彩蛋）

点出非法的组合不会被执行，而是弹出教学提示，例如：

> ❌ 凝华需要从「气态」开始，你现在是「液态」
> 💡 凝华是气态直接变固态，不经过液态！

### 六种变化速查

| 变化 | 方向 | 能量 |
|---|---|---|
| 熔化 | 固 → 液 | 吸热▲（加热） |
| 凝固 | 液 → 固 | 放热▼（冷却） |
| 汽化 | 液 → 气 | 吸热▲（加热） |
| 液化 | 气 → 液 | 放热▼（冷却） |
| 升华 | 固 → 气 | 吸热▲（加热） |
| 凝华 | 气 → 固 | 放热▼（冷却） |

### 干扰牌

| 干扰牌 | 效果 |
|---|---|
| 🥤 保温杯 | 对手下次出变化牌需**多付 1 张**能量牌 |
| 🍃 风口 | 对手下回合**只能**出「汽化」，做不到就被吹过回合 |
| 🔥 热浪 | 弃掉对手 1 张「冷却」牌 |
| 🥶 寒流 | 弃掉对手 1 张「加热」牌 |

### 回合流程

1. 出一张牌（变化牌 / 干扰牌），或**跳过回合**（连击清零）
2. 自动补 2 张牌（跳过只补 1 张）
3. 轮到对手

### 计分与胜利

- 每次合法相变 **+2 分**
- 同一玩家连续 3 次成功相变 → **三连击 🔥 额外 +3 分**
- **先到 10 分获胜**

## 🏫 课堂使用建议

- **投屏 2v2**：双人对战模式下双方手牌互相可见，围观小组可以一起讨论"该出哪张"，把全班卷进决策
- **人机热身**：先用"人机对战"让学生熟悉规则，再组织组间对抗
- **裁判角色**：每组指定一名"记录员"，负责核对得分与合法性
- **课后延伸**：让学生自己设计新的干扰牌（如"高压锅""撒盐"），写清效果即是一次很好的知识应用练习
